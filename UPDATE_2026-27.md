# Data update: full 2026-27 Booth year

Drop-in update for the schedule builder repo. Paths match the repo layout. Merge test files by hand if the repo's versions have changed since the first release; replace the other files.

## Files

| File | Change |
|---|---|
| `scripts/parse_booth.py` | Reads one-quarter or full-year Course Search pages. Adds `term`, `units` (50 or 100), `half` (`"first"`, `"second"`, `"all"` or `null` for 50-unit courses) and `tags` (Booth's own requirement tags). Notes "Time TBD" and "Day not listed: …". Never reads personal status fields. |
| `scripts/parse_laws.py` | Adds `term: "Winter 2027"`, `units`, `half` and empty `tags`, so Law records match the Booth shape. |
| `data/booth_sections.json` | 580 sections: Autumn 2026 (182), Winter 2027 (188), Spring 2027 (210). Winter ids and fields are unchanged, so saved schedules still load. |
| `data/law_sections.json` | Same 98 Winter 2027 sections, with the new fields. |
| `data/raw/booth_details.json` | Descriptions for all 580 Booth sections and bios for 247 Booth faculty (Winter capture plus the full-year capture). |
| `data/details.json` | Regenerated with `scripts/parse_details.py`: 678 sections, 351 professors. |
| `tests/test_parse_booth.py`, `tests/test_parse_laws.py`, `tests/test_build.py` | New tests for full-year parsing, TBD times, missing days, 50-unit flags, tags and personal-field exclusion; build counts updated to 678 sections across three quarters. |

## Section record (all quarters)

`{"id", "dept", "term", "code", "sec", "name", "fac", "meets": [{"d", "s", "e"}], "note", "cap", "units", "half", "prog", "remote", "tags": {"areas", "rules"}}`

- Section ids are unique across the year. Course numbers repeat across quarters, so a course must be keyed by quarter plus number.
- `tags` agree with `data/booth_requirements.json` on every Foundations and FLMBE row for all 580 sections. Requirement logic should keep using `booth_requirements.json`; `tags` are reference data.
- 12 Spring sections have no meetings (11 "Time TBD", plus 35000-81, whose listing gives hours but no day).
- No Summer 2027 courses were listed. Law School data covers Winter 2027 only.

## Regenerate

```bash
python scripts/parse_booth.py "booth_intranet.html" > data/booth_sections.json
python scripts/parse_laws.py data/raw/law_classes_w27.txt > data/law_sections.json
python scripts/parse_details.py data/raw/booth_details.json data/raw/law_details.json data/raw/law_faculty.json data/law_sections.json > data/details.json
python scripts/build.py
```

The saved Booth page is not included because it contains the account holder's session and student details.
